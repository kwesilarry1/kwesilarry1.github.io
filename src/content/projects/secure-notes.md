## Overview

Secure Notes is a note-taking application built with Flutter. The project explores practical application development alongside security concepts such as authentication, authorization, input handling, and secure data management.

## Features

* Create notes
* View notes
* Edit notes
* Delete notes
* PIN-based access control
* Responsive web interface

## Security Focus

The project is also used as a practical environment for exploring application security concepts and identifying areas where insecure design or implementation could introduce vulnerabilities.

## What I Learned

Building Secure Notes helped me connect software development with application security by thinking about security requirements during development rather than treating security as something added afterward.
